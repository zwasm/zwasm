# What this directory is supposed to contain.
#
# The runner walks for `<case>.wasm` with a sibling `<case>.expect` and reports
# pass/fail. That alone cannot distinguish a directory whose fixtures were
# never produced from one where every fixture passes — both yield zero
# failures. This file supplies the missing half.
#
#   <dir> expect=fixtures            must yield at least one checked fixture
#   <dir> expect=skip reason=<text>  announced with its reason, does not fail
#
# This is a ledger, not a roster: every directory in the corpus must appear
# here, and one that does not fails the lane. Listing only what someone
# remembered to list would close today's silent green and leave the next one
# open — a new directory holding nothing but a README would pass unmentioned,
# which is the defect this file exists to remove.
#
# So adding a directory means adding a line here.
#
# The enumeration is top-level only. Fixtures are counted recursively, so
# an empty directory nested inside a listed one is not caught here.

clang_O0_arr_sum   expect=fixtures
clang_O0_fp_sum    expect=fixtures
clang_musttail     expect=fixtures
clang_wasm64       expect=fixtures
moonbit            expect=fixtures
rust_bubble_sort   expect=fixtures
rust_data          expect=fixtures
rust_fib           expect=fixtures
rust_loop_sum      expect=fixtures
